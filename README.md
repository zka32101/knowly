# Knowly（ノウリー）

就学前から大人まで、世界中で楽しめる雑学アプリ（Flutter）。設計は [`docs/knowly_design_v2_global.md`](docs/knowly_design_v2_global.md)。

## できていること（v1.0 の土台）

- **メニュー**: 下のタブ（ホーム／あそぶ／あつめる／さがす／せってい。Kids は先頭の3つで、設定は保護者ゲートの先）。あそぶ＝クイズ・スワイプ・チャレンジ・おさらい・ほんと？うそ？、あつめる＝相棒・ずかん・カプセル・バッジ、さがす＝ライブラリ・保存・関心事・今日は何の日・ながら聞き・自由研究
- **アプリ名**: 日本語は「ノウリー」、ほかの言語は Knowly。見た目はふくろう色（琥珀）のやわらかいテーマ（ダーク対応）
- **年代モード**: Kids（就学前）/ Junior（小学生）/ Teen / Adult。生まれた年から年代を提案（若いほうに見積もる）。生まれた年は保存しない
- **Kids**: 1画面1雑学、大きな絵、端末内の読み上げ（`flutter_tts`）
- **Junior〜Adult**: 日替わりの雑学フィード（現地日付で決定。世界で同じ日に同じ雑学ではなく、各自の現地日付基準）
- **Teen/Adult**: 利用シーン・カテゴリーの絞り込み、コピー、保存、評価（へぇ/使える/スゴイ）
- **保護者ゲート**: 子どもモードからのモード変更・プレミアム案内の前に表示
- **多言語**: 画面は日本語・英語・中国語（簡体）・韓国語・スペイン語の5言語（ARB）。端末の言語に追従し、設定・最初の画面で変更できる。雑学の本文は日本語・英語のみで、ほかの言語の画面では本文は英語（自動）。ARB のキー・プレースホルダーの一致はテストで確認
- **コンテンツ**: 60件 × 4年代 × 日英（`assets/trivia/trivia.json`）。カテゴリーは動物・むし・のりもの・たべもの・宇宙・からだ・自然・科学・地理
- **子ども向けUI**: Kids は文字1.3倍・大きなボタン、Junior は1.15倍。Kids の設定は保護者ゲートの先
- **無料/プレミアムの枠**: Kids/Junior は全て無料。Teen/Adult は無料で7日分・保存20件まで
- **毎日の通知**: 端末内の予定通知（サーバー・通信なし）。先の14日ぶんを予定し、各日の通知は「その日の今日の雑学」と同じ。Teen/Adult は設定でオン、Junior は保護者ゲートの先、Kids はなし
- **他アプリ紹介**（`cross_promo_kit` v0.3.0）: Teen/Adult の設定画面だけ。Kids/Junior では Firebase に接続しない

## 検索・フィルター・関心事（Junior〜Adult）

- **ライブラリ**: 全雑学を一覧。検索（ひらがな/カタカナ/英字の大文字小文字を区別せず、日本語と英語のどちらのことばでも探せる）とフィルター（ジャンル・シーン・状態＝保存済み/知ってた/知らなかった/未評価）。無料の Teen/Adult は、無料の範囲外に鍵がつく（タップでプレミアム案内）
- **関心事の登録**: ジャンル・シーン・キーワード（最大10個）を登録すると、ホームに「あなたの関心」（日替わり。無料2件・プレミアム5件）が出る。端末内にだけ保存
- 一時的な絞り込み（ホームの「絞り込み」）と、関心事（登録して残る）は別。Kids は登録した「すきなもの」のジャンルだけが出る

## 季節・記念日・国・Kids の安全（v1.0）

- **季節・時間帯・記念日のおすすめ**: 「今日の雑学」は季節外れを避け、記念日（例: 10/1 の新幹線の開業日）の当日はその雑学になる。ホームに「いまのおすすめ」（夏にぴったり／夜にぴったり／今日は記念日／週末に家族で）を理由つきで出す。南半球は季節を反転（タイムゾーンから推定。位置情報は使わない。設定で北/南/オフも選べる）
- **国タグ**: 国限定の雑学は `regions` タグで管理し、選んだ国（既定は端末の地域）でだけ表示。設定で国を変えられる
- **Kids/Junior の安全**: 話題のタグ（性・暴力・戦争・死・宗教・政治・酒たばこ薬物・賭け事・怖い・差別・犯罪・医療）が1つでもあれば出さず、文章・クイズに不適切なことばがないことをテストで確認
- **Junior のふりがな**: 漢字のあとに読みを添える（`血（ち）`）。Kids はひらがなのみ
- **情報管理**: 雑学ごとに公開状態・版・出典・検証・見直し期限・検索キーワード・関連を持つ。出典と検証のない雑学は `reviewed` にできない（テストで強制）。詳細は [`docs/content_guide.md`](docs/content_guide.md)

## 差別化機能（追加分）

- **「なぜ？」チェーン**: 詳細の「なぜ？」で、関連する雑学へ1段ずつ深掘り（3回続けるとほめる）。Kids はホームの「なぜ？」ボタンで次の雑学へ（`why_chains.json`）
- **ほんと？うそ？**: よくある勘違い16問＋意外な本当4問の○×。全年代（Kids は難しいものを除く）（`myths.json`）
- **今日は何の日**: 国際デー13件＋日本の行事9件＋記念日つきの雑学。ホームのバナーと「今日は何の日」画面。国限定は国タグで管理（`calendar.json`）
- **雑学で英語**: 各雑学に対訳のことば。日本語の画面は英語、英語の画面は日本語を学べる。タップで発音、「英語で聞く／日本語で聞く」で別の言語をゆっくり読み上げ
- **ながら聞き**（Teen/Adult）: 今日の雑学→おすすめ→関心→これまでの雑学を連続で読み上げ。再生/一時停止/前後/速さ。画面を消したり他のアプリに切り替えても続く（Android はメディア通知、iOS はバックグラウンド音声。実機で未確認）
- **自由研究ネタ帳**（Junior/Teen/Adult）: 雑学から家でできる実験12テーマ。材料・手順・観察のポイント・安全上の注意。おとなが必要なテーマにはバッジ。Junior は「漢字（よみ）」、Teen/Adult は漢字のみ（`projects.json`）

## 競合との差別化機能

- **親子モード**: Teen/Adult の詳細画面で「こどもに説明するなら」→ 小学生向け / 就学前向けの説明に切り替え。同じ雑学の4年代版を持っているから実現できる
- **二言語表示**: 日本語と英語を並べて表示（Kids を除く）
- **「知ってた / 知らなかった」**: 端末内に保存し、設定に「知っていた雑学の割合」を表示
- **ストリーク（Teen/Adult のみ）**: 7日続くと「お休み券」がもらえ、1日休んでも途切れない。Kids/Junior は連続日数で煽らない（記録もしない）
- **クイズ**: ○×52問＋選択式32問（4択・2択の比べっこ）。ひとり〜4人の対戦（1台を回して遊ぶ）。ジャンル・種類・時間制限（速く答えるほど同点の決着に使う得点）を選べる。結果は保存しない（ひとり・復習・チャレンジの正解数だけ通算に加える）
- **おさらい（復習）**: 「知らなかった」を押した雑学を、1・3・7・14・30日後に再出題。正解で間隔が伸び、間違えると明日に戻る
- **今日のチャレンジ**: 毎日3問（日付で決まるので同じ言語・年代なら同じ問題）。1日1回、結果を記録。Teen/Adult は結果を共有できる
- **相棒（成長するキャラ）**: 雑学を開くと +1、「知らなかった」を覚えると +2 で成長し、たまご→ひよこ→ちびふくろう→ふくろう→はかせ→おう と姿・ひとことが変わる。連続日数は使わないので Kids/Junior にも出す。今は絵文字の仮表示（`mascot_<id>` の画像に差し替える）。ホームのカードから成長の一覧へ
- **ことばの説明**（Junior英語/Teen/Adult）: 本文の難しいことば（ヘモシアニン・液果・水素結合など56語、日英）に点線の下線がつき、タップすると説明のサブ画面が開く。やさしい説明＋（Teen/Adult は）くわしい説明、そのことばが出てくる雑学の一覧、読み上げ。同じことばは本文の最初の1か所だけ。Kids と日本語の子ども向けは対象外（`glossary.json`）
- **ことばずかん**（Junior英語/Teen/Adult）: 説明を見たことばが貯まる図鑑（まだは「？？？」）、今日のことば（日付で決まる）、ことばクイズ（「○○」の意味は？の4択・10問）
- **つながりマップ**: 雑学の `related` を、中心と周りの星座のような図で。タップで中心が移り、見ていない雑学は「？」。詳細の「つながりを見る」からも開ける
- **みみでクイズ**: 問題・選択肢を読み上げ、大きなボタンで答える。結果と解説も読み上げ。Kids も遊べる
- **かぞくリーグ**（端末内）: 2人以上の対戦の得点（正解数＋勝ちボーナス3）を、月曜はじまりの週ごとに集計。先週の優勝者 👑、今週の記録を消せる。名前は端末内だけに保存
- **週のふりかえり**: 1日ごとの記録（見た・知れた・クイズ・回答）から、直近7日と前の7日の比較、1日ごとの棒グラフ。日曜日はホームにお知らせ
- **きせつのスタンプちょう**: いまの季節にぴったりの雑学を開くとスタンプ（半球はタイムゾーンから推定）。1つの季節で3つ集めると完成し、相棒がその季節の飾り（🌸🌻🍂🧣）をつけてお祝い
- **SNS共有（Teen/Adult のみ）**: 雑学・クイズ対戦（順位つき）・スワイプ・今日のチャレンジ・カプセル（レア度の色）・ふりかえり・ずかん・バッジ・相棒・ことば・リーグ を、画像カード（PNG）＋ハッシュタグつきの文で共有。Kids/Junior は共有しない
- **めくりカード**: ホームの「今日の雑学」が、おもては「ほんと？うそ？」、タップでくるっと裏返って答えと本文が出る（めくると見た雑学になる）
- **お祝い演出**: 相棒が成長したとき・バッジを取ったとき、紙吹雪つきで3秒表示（既存の記録は最初の起動でお祝いしない）。相棒は、クイズで正解なら喜び・不正解ならしょんぼり、ながら聞き中は口ぱく、さわるとよろこぶ
- **ざつがくカプセル**: 1日1回あけると雑学カードが1枚（ふつう60%／レア30%／スーパーレア10%、見ていないものを8割ねらう）。お金・課金とは無関係。Kids にも出す（「ガチャ」とは呼ばない）
- **ざつがくずかん**: 見た雑学がジャンルごとのマスに埋まる。レア度の星・枠つき。まだのマスは「？」
- **スワイプ ほんと？うそ？**: カードを右（ほんと）・左（うそ）に。れんぞく正解、10問、直前の解説つき
- **バッジ**: 連続日数・読んだ日数・知れた数・クイズ正解数・チャレンジなど13個。Kids/Junior には連続日数のバッジを出さない
- **保護者向けの学習のよう**（Kids/Junior の設定内。Junior は保護者ゲート）: 知れた数・クイズの正解率・よく見たジャンルなど。端末内の記録だけから作る
- **画像でシェア・出典表示**（Teen/Adult）: 今日の雑学をカード画像にして共有。出典があれば詳細に表示
- **ホーム画面ウィジェット**（Android・Teen/Adult）: 今日の雑学。アプリを開くたびに先の7日ぶんを更新
- **プライバシー画面・データ削除**: 設定から。Kids/Junior は保護者ゲート

## コンテンツの公開ルール

`assets/trivia/trivia.json` の各翻訳には `reviewStatus`（draft / reviewed / published）がある。
**リリースビルドでは draft を配信しない**（`kAllowDraftContent`）。ネイティブ話者・事実確認のレビューが済んだものを `reviewed` に変える。
デバッグビルドでは draft も表示される。

## 開発

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

`cross_promo_kit` は git 依存（プライベートリポジトリ）。取得できない環境では GitHub の認証を設定する。

## 設計上の判断メモ

- `app_common_kit` は使っていない。広告 SDK（`google_mobile_ads`）を依存に含み、子ども向けアプリの要件（広告 ID の権限なし）と衝突するため。保護者ゲートは `lib/widgets/parental_gate.dart` に同等のものを持つ
- applicationId / bundle ID は `com.yourwish.knowly`
